# Agent 图标资产

顶部 Agent 切换器、智能体状态列表和当前路由摘要统一使用 128×128 PNG，以避免运行时
依赖用户本机应用资源。未知 Agent 使用内置通用图标降级，不从用户应用中动态提取资源。

| 文件 | 来源 |
| --- | --- |
| `workbuddy.png` | WorkBuddy macOS 官方应用 `icon.icns` |
| `codebuddy.png` | CodeBuddy CN macOS 官方应用 `CodeBuddy CN.icns` |
| `qclaw.png` | QClaw macOS 官方应用 `icon.icns` |
| `autoclaw.png` | AutoClaw macOS 官方应用 `icon.icns` |
| `codex.png` | OpenAI 官方 ChatGPT/Codex 应用图标 |

这些图标只用于识别对应产品。产品名、图标和商标归各自权利人所有；正式对外发布
前应再次确认当期品牌使用规范。上游应用更新品牌资产时，应同步替换这里的打包副本。
