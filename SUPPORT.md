# Support

## Usage Questions and Bug Reports

Use [GitHub Issues](https://github.com/atswitch/at-switch/issues) for reproducible
bugs and feature requests. Before opening an issue, search existing issues and
include:

- AT-Switch version;
- operating system and CPU architecture;
- affected Agent and its version;
- direct or local-proxy mode;
- exact reproduction steps and the visible error message.

Screenshots and logs must be redacted. Do not include API keys, credential values,
complete Agent configuration files, personal paths, prompts, responses, or other
private data.

General usage questions may also be opened as an Issue until a dedicated community
discussion channel is available.

## Security Vulnerabilities

Do not report vulnerabilities in public Issues. Follow the private reporting
instructions in [SECURITY.md](./SECURITY.md).

## Scope

Community support is best effort. The maintainers cannot provide support for
third-party Provider availability, billing, account restrictions, or undocumented
Agent internals.
